## The 1-line story (memorize this as a team)
> **Design the data → get data in → operate on it daily → turn it into insight & keep it safe.**

## Demo is ONE continuous story (rehearse this order)
1. **Marco** traces a click → API → SQL → JSON (architecture).
2. **Member 2** registers a brand-new member live.
3. **Member 3** times that same member in.
4. **Member 4** shows that member's payment appear in the revenue report, then shows the audit log + a failed-login lockout.

The data visibly flows from one presenter to the next. Professors love this.

## Tech stack one-liner
React + Vite single-page app → PHP REST endpoints → MySQL (MariaDB) database, hosted on InfinityFree.
